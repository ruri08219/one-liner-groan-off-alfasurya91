Entry for the [make.fun](https://make.fun) competition
[The One-Liner Groan-Off](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5)
— one original one-line dad joke, at most 140 characters.

## The entry

> I told my vacuum it was doing a great job. It said, 'I suck at taking compliments.'

83 characters, one line, no trailing newline. The setup is a dad praising the
vacuum; the punchline turns the vacuum's literal job ("I suck") into a joke
about taking compliments — fast, tight, and groan-worthy.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$OUTPUT_DIR` (default `/output`). Exits 0 on a valid
entry; exits 1 (writing nothing) on an empty, over-long, multi-line, or
control-character entry.
